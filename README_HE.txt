# מסה נקייה — גרסה 12

## תיקון חלון ההחלפה באייפון
גרסה זו מתקנת את חישוב גובה חלון ההחלפה לפי ה־Visual Viewport של Safari, ומקצה את כל הגובה הפנוי לרשימת המזונות כדי למנוע אזור לבן/מוסתר בחלק התחתון.

## עדכון האתר הקיים
1. ייצא גיבוי מתוך האפליקציה לפני העדכון.
2. חלץ את קובץ ה־ZIP.
3. העלה את כל הקבצים מתוך התיקייה `masse_clean_pwa_v12` לשורש המאגר הקיים ב־GitHub Pages והחלף את הקבצים הקודמים, במיוחד `index.html` ו־`sw.js`.
4. המתן לפרסום, פתח את אותו אתר ב־Safari ורענן. אין צורך ליצור פרויקט חדש.
5. בדוק את חלון ההחלפה ואת הגלילה.

הנתונים נשמרים באחסון המקומי של הדפדפן. שמור גיבוי ואל תעלה את קובץ הגיבוי למאגר הציבורי.
