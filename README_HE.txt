מסה נקייה — תכנון ומעקב ארוחות (גרסה 4 — עיצוב בהיר)
========================================

מה חדש בגרסה הזו:
- תפריט בסיסי בארבע ארוחות שמוכן לעריכה.
- רישום מתוכנן בנפרד מרישום מה שבאמת נאכל.
- סימון כל פריט או סימון כל הארוחה כ"נאכל"; רק פריטים שסומנו נכנסים לסיכום היומי.
- החלפת מזון במזון מאותה קבוצת מזון, עם כמות מוצעת שמותאמת לפי חלבון / פחמימות / שומן מרכזי בקבוצה.
- אפשרות לשנות כמויות ולקבל חישוב מחדש.

בדיקה במחשב:
1. פתחו את masse_clean_app_v4.html ב-Chrome או Edge.
2. עברו על ארבע הארוחות: הפריטים הראשוניים הם תכנון לדוגמה, ולא מסומנים כאילו נאכלו.
3. לחצו "החלפה" כדי לבחור מזון אחר מאותה קטגוריה.
4. סמנו תיבה ליד מזון רק אחרי שאכלתם אותו; הסיכום היומי מתעדכן לפי הסימונים.
5. לחצו "גיבוי" מדי פעם ושמרו את קובץ ה-JSON במקום בטוח.

העברה לאייפון בחינם (אתר שמתווסף למסך הבית):
1. היכנסו ל-GitHub וצרו repository חדש בשם masse-clean. במסלול חינמי, GitHub Pages בדרך כלל דורש repository ציבורי; הקוד וכתובת האתר יהיו פומביים.
2. העלו את כל קובצי התיקייה masse_clean_pwa_v4 ישירות לשורש repository: index.html, manifest.webmanifest, sw.js, icon.svg, icon-192.png, icon-512.png.
3. פתחו Settings > Pages. תחת Build and deployment בחרו Deploy from a branch, בחרו main ואת /(root), ולחצו Save.
4. המתינו לקישור HTTPS, פתחו אותו ב-Safari באייפון.
5. לחצו Share > Add to Home Screen > Add. אם מופיע Open as Web App, אפשר להפעיל.

פרטיות ונתונים:
- תכנון המזון, הסימונים והמדידות נשמרים באחסון המקומי של הדפדפן במכשיר. אין סנכרון אוטומטי בין מכשירים.
- אל תעלו גיבוי JSON אישי ל-repository ציבורי.
- ניקוי נתוני הדפדפן עלול למחוק מידע. שמרו גיבוי מדי פעם.
- אתרים שפורסמו דרך GitHub Pages נגישים לכל מי שיש לו את הקישור. האפליקציה לא כוללת חשבון משתמש או שרת ששומר את נתוני הארוחות.

חשוב לגבי החלפת מזונות:
כמות החלופה מוצעת לפי המאקרו המרכזי בקטגוריה, ולכן היא אומדן תכנוני ולא תחליף מדויק מבחינה תזונתית. לאחר ההחלפה אפשר לערוך את הכמות. במוצרים ארוזים יש להשתמש בתווית היצרן.


עדכון גרסה 4: עיצוב בהיר ורך בגווני אפור-לבנדר וקורל, כרטיסים בהירים, טקסט עם ניגודיות גבוהה וסרגל ניווט תחתון צף במובייל. אין שינוי במאקרו, במאגר המזון או בלוגיקת הסימונים.
