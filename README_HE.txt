מסה נקייה — גרסה 11 (שמירה משופרת, תיקון חלון החלפה ותיקון אייקון)

מה חדש:
• שמירה אוטומטית מקבילה: localStorage + עותק התאוששות ב־IndexedDB.
• שחזור אוטומטי בעת פתיחה אם עותק IndexedDB חדש יותר מהעותק ב־localStorage.
• שמירה גם כשהאפליקציה עוברת לרקע או נסגרת (בנוסף לשמירה אחרי כל שינוי).
• חלונית ההחלפה באייפון משתמשת בכל גובה המסך הזמין; רשימת המזונות יכולה לגלול עד לתחתית, בלי חצי מסך ריק.
• קובצי אייקון חדשים בשם ייחודי והפניה מפורשת ל־apple-touch-icon ול־manifest כדי למנוע אייקון אפור מהמטמון.

עדכון GitHub Pages:
1. באפליקציה הקיימת בחר ״שמירת גיבוי״ לפני העדכון.
2. חלץ את קובץ ה־ZIP. פתח את התיקייה masse_clean_pwa_v11.
3. העלה את כל הקבצים שבתיקייה ישירות לשורש המאגר הקיים ב־GitHub, והחלף קבצים בעלי אותו שם.
4. המתן לסיום הפרסום. פתח את האתר ב־Safari ורענן.
5. כדי לרענן את האייקון באייפון: אחרי שהאתר המעודכן זמין, הסר רק את קיצור הדרך הישן ממסך הבית והוסף אותו מחדש מ־Safari. אין למחוק את נתוני האתר או את נתוני Safari.

שמירה והיסטוריית ימים:
• הנתונים נשמרים אוטומטית במכשיר. IndexedDB הוא עותק התאוששות נוסף; הוא לא מסנכרן אוטומטית בין מכשירים.
• כל תאריך נשמר בנפרד. אחרי חצות האפליקציה מציגה את היום החדש; נתוני היום הקודם נשארים בשמירה, אבל המסך הראשי מציג את היום הנוכחי.
• מומלץ לשמור גיבוי JSON מפעם לפעם. אין להעלות את קובץ הגיבוי האישי למאגר GitHub ציבורי.
• אין למחוק נתוני Safari/אתר בזמן פתרון תקלה, כי זה עלול להסיר את העותק המקומי.
