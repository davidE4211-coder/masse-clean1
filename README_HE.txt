מסה נקייה — גרסה 10

מה חדש:
• תפריט בסיסי חדש של ארבע ארוחות נוחות, עם קורנפלקס צהוב תלמה, חלב 3%, משקה PRO 0% קפה, עוף ואורז, כריך עם סימפוניה, טונה ופיתה.
• נוסף משקה PRO שוקולד-אגוזים 0% כאפשרות להחלפה.
• נוספה חסה למאגר ולהרכבת הארוחות.
• נוסף עיגול מעקב מים כחול, עם הוספה מהירה של כוס (250 מ״ל) או חצי ליטר, הזנה לפי כוסות/ליטרים/מ״ל, ויעד מעקב שאפשר לשנות.
• נתוני המים היומיים נשמרים יחד עם היום ונכללים בקובץ הגיבוי.
• גרסת מטמון השירות עודכנה ל־v10.

ערכי תזונה:
• קורנפלקס צהוב תלמה: 375 קל, 7 ג׳ חלבון, 83.3 ג׳ פחמימות, 0.9 ג׳ שומן ל־100 ג׳, לפי דף המוצר הרשמי של תלמה.
• PRO קפה 0%: 37 קל, 7.2 ג׳ חלבון, 2.1 ג׳ פחמימות, 0 ג׳ שומן ל־100 מ״ל; בקבוק 350 מ״ל מכיל כ־130 קל וכ־25.2 ג׳ חלבון.
• PRO שוקולד-אגוזים 0%: 40 קל, 7.2 ג׳ חלבון, 2.1 ג׳ פחמימות, 0 ג׳ שומן ל־100 מ״ל; בקבוק 350 מ״ל מכיל כ־140 קל וכ־25.2 ג׳ חלבון.
• בערכי משקאות, האפליקציה מתייחסת ל־1 מ״ל ≈ 1 ג׳ לשם חישוב. יש להעדיף את התווית שעל האריזה אם היא שונה.

נתוני התפריט מחושבים מאותו מאגר לכל פריט ולסכומי הארוחות. מזון מבושל נמדד אחרי הבישול, אלא אם מצוין אחרת. יחידות ביתיות הן קירוב.

עדכון GitHub Pages:
1. שמור גיבוי מתוך האפליקציה הישנה.
2. חלץ את ה־ZIP והעלה את כל הקבצים שבתיקייה masse_clean_pwa_v10 לשורש המאגר הקיים.
3. החלף index.html ו־sw.js וכל קובץ בעל אותו שם. אל תעלה קובץ גיבוי אישי למאגר.
4. אחרי שהאתר פורסם, פתח אותו ב־Safari ורענן. אם נראית הגרסה הישנה, סגור את אפליקציית מסך הבית ופתח מחדש.

הנתונים האישיים נשמרים באחסון מקומי בדפדפן ואינם כלולים בקובצי האתר. מומלץ לשמור גיבוי לפני עדכונים או ניקוי נתוני Safari.
